# Tank Runner (TIC-80, Lua)

Прототип: танк едет “вперёд” по бесконечной местности, объезжает препятствия и стреляет по разрушаемым объектам (пока — стены).

## Запуск

- Открой `tank_runner.lua` в TIC-80 (Lua cart) и запусти.

## Управление

- Left/Right: поворот
- A: выстрел
- B: тормоз (временно, для ощущения скорости)

## Что уже есть (вертикальный срез 0)

- Псевдо-перспектива (horizon) и ощущение движения
- Спавн препятствий: дерево/камень/стена (стена разрушается выстрелами)
- Очки, здоровье, Game Over, смена “биома” по времени

## Дальше по плану

- Настоящий “пересечённый ландшафт”: высоты/трамплины, прыжки и мелкие препятствия
- Стабильные биомы (лес/пустыня/синий) с разными наборами объектов и цветов
- Спрайты для танка/объектов, нормальная физика столкновений и пули
