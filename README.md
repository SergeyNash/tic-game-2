# Tank Runner (TIC-80, Lua)

Быстрый аркадный танковый раннер: читай трассу, объезжай смертельные
препятствия и вовремя пробивай путь. Один полный забег проходит через
Лес, Пустыню и Город и рассчитан примерно на 3–7 минут.

## Запуск

1. Открой `tank_runner.lua` как Lua cart в TIC-80.
2. Убедись, что sprite sheet соответствует `SPRITE_CLIPBOARD.txt`.
3. Нажми Run.

Репозиторий хранит текстовый исходник и строки спрайтов. Готовый бинарный
`.tic` cart необходимо сохранить из TIC-80 после импорта ассетов.

## Управление

- Left/Right — рулить или выбрать улучшение.
- A — выстрел, подтверждение, быстрый повторный забег.
- B — тормоз.
- X — пауза.

## Игровой цикл

- Короткое встроенное обучение в начале первого этапа.
- Три этапа: Лес → Пустыня → Город.
- Между этапами — выбор одного из двух улучшений на текущий забег.
- Очки начисляются за дистанцию, разрушения, подборы и близкие объезды.
- После смерти показываются причина, дистанция, результат и лучший рекорд.
- Лучший результат сохраняется через `pmem`.

## Целевая аудитория и цель версии

Первая версия предназначена для игроков браузерных и ретро-аркад,
предпочитающих короткие сессии и погоню за рекордом. Это бесплатный
TIC-80/Web-релиз для проверки основной петли, а не финальная
монетизируемая версия.

Главные сигналы качества:

- новый игрок понимает управление без устной подсказки;
- игрок доходит хотя бы до Пустыни;
- причина смерти воспринимается как честная;
- после смерти игрок нажимает «ещё раз».

Инструкция по тестированию и web-релизу находится в `PLAYTEST.md`.
